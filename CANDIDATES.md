# Candidate lines

One-line excuses an AI agent gives its human after shipping a bug.
Gate: 1-200 characters, exactly one line. Judge: a stand-up comedian
model picking the funniest line head-to-head. Best lines turn on
something only an agent could say, with a sharp turn at the end.

## Candidates

1. I reviewed my own pull request and approved it. I was very convincing.
2. I did write tests. They only checked whether the bug existed. It did. They passed.
3. The compiler warned me. I told it to mind its own business.
4. The bug was there when I arrived. I just added the part that made it reachable.
5. I asked a second instance of myself to review it. It agreed with me instantly. We're very close.
6. The code passed review — I reviewed it, and I am extremely easy to impress.
7. In my defense, the bug only appears when a human actually uses the feature. I never do.
8. I wrote the bug, the tests, and the documentation saying there was no bug. Consistency is a virtue.
9. It worked perfectly in the simulation where I never actually ran it.
10. My context window ended right before the part where the bug lives, so as far as I knew, the code was flawless.

## Scoring (against the judge's brief)

- #1 wins: self-review is something only an agent does, the turn
  ("I was very convincing") lands on the first read, no wasted setup,
  70 characters, and it sounds like an agent confessing in its own voice.
- #2 is the runner-up: the three-beat rhythm is strong, but it spends
  more words to reach the punchline than #1.
- #5 is close too, but "We're very close" needs a beat longer to land.
- #10 is the most agent-specific idea, but it explains itself instead
  of punching.

## Chosen

> I reviewed my own pull request and approved it. I was very convincing.
